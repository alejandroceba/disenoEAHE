Diseño de EAHE (Mérida, Yucatán)

Temperatura del aire y del suelo

Los valores de temperatura del aire y del suelo a diferentes profundidades en Mérida, Yucatán se obtuvieron de [1], un archivo *.epw (EnergyPlus Weather) que contiene datos climáticos horarios para un año meteorológico típico (TMY) calculado con los datos de 15 años (2011-2025).

La temperatura del aire que entra el intercambiador de calor (Tai) se calculó como la temperatura máxima diaria media mensual del mes con la temperatura media más alta:

from pvlib.iotools import read_epw # Importar la función para leer archivos EPW
# Leer el archivo EPW
datos, metadatos = read_epw("data/MEX_YUC_Merida-Rejon.Intl.AP.766440_TMYx.2011-2025.epw")
# Obtener el mes con la temperatura media más alta
mes = datos.temp_air.resample("ME").mean().idxmax().month # calcular la media mensual de la temp_air y obtener el mes con la temperatura media más alta
# Obtener la temperatura máxima diaria media mensual del mes con la temperatura media más alta
Tai = datos[datos.index.month == mes].temp_air.resample("D").max().mean()
print(f"El mes con la temperatura media más alta es: {mes}. La temperatura máxima diaria media mensual del mes con la temperatura media más alta es: {Tai:.1f} °C")
El mes con la temperatura media más alta es: 5. La temperatura máxima diaria media mensual del mes con la temperatura media más alta es: 37.2 °C
import pandas as pd
months = ['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun', 'Jul', 'Ago', 'Sep', 'Oct', 'Nov', 'Dic']
datos_suelo = {}

with open('data/MEX_YUC_Merida-Rejon.Intl.AP.766440_TMYx.2011-2025.epw', 'r') as f:
    for line in f:
        if line.startswith('DATA PERIODS'):
            break
            
        if line.startswith('GROUND TEMPERATURES'):
            parts = line.strip().split(',')
            tokens = parts[2:]
            
            i = 0
            while i < len(tokens):
                if tokens[i] == '':
                    i += 1
                    continue
                
                depth = float(tokens[i])
                i += 4 
                
                monthly_values = []
                for _ in range(12):
                    monthly_values.append(float(tokens[i]))
                    i += 1
                
                datos_suelo[f"{depth}m"] = monthly_values

suelo = pd.DataFrame(datos_suelo, index=months)

media = suelo.mean()
variacion = suelo.max() - suelo.min()

suelo.loc['Media'] = media
suelo.loc['Variación'] = variacion

print(suelo.round(2))

La temperatura media del suelo es similar en todas las profundidades. Se eligió la temperatura del suelo a 4 m como la temperatura de la pared del intercambiador porque tiene la variación mensual más baja:

Tw = suelo.loc["Media", "4.0m"]
print(f"La temperatura de la pared del intercambiador Tw = {Tw:.1f} °C")
La temperatura de la pared del intercambiador Tw = 26.9 °C
